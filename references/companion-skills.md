# Required Companion Skills

## Responsibilities

- `z-files-folders` owns file placement, current folder-policy lookup, approved account and root boundary, names, duplicate checks, upload mechanics, and read-back.
- `z-agent-communication` owns clear human-facing wording. It does not grant service access or approve publishing.
- `z-ai-skill-developer` owns authorized skill development, validation, packaging, pilot checks, and release approval. It is not a new image-generation or Drive connection.

Load the current approved installed companions when available. If they are missing, obtain the source through the approved connector and read it. Do not silently invent or replace their rules. Installing or upgrading a companion beyond the current task requires the applicable approval.
